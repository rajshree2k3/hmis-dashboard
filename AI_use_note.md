# AI-use note

I used an AI coding agent (Claude Code, Anthropic) heavily in this assignment: most of the code and the first draft of the report and slides were AI-generated, under my direction. It found the download paths on the HMIS portal, wrote the Python code to parse the SAS-HTML and Excel exports, built the district crosswalk, the indicators, the data-quality checks and the Streamlit dashboard, and drafted the report text. All inputs were public, aggregated district-level statistics (HMIS standard reports and NFHS-5 factsheets). No personal, identifiable or non-public government data was shared with the tool. I also kept to the HMIS portal's public listings: years shown only to logged-in users were not accessed. Its output was checked as follows. Every number in the report is generated by the code from the source files, not typed in. The pipeline's internal checks passed: the 12 monthly files re-sum exactly to the annual file, and public + private equals total. The AI's reading that negative NFHS values mean "25–49 cases" was verified against a second NFHS file with explicit notes. Two errors in early drafts were caught and corrected by recomputing from the data: the number of districts where first-trimester registration was over-reported, and a rounding inconsistency between the report and slides. The dashboard was tested across all filter combinations. My own role was to set the scope and make the choices about output format and hosting. I deployed the dashboard myself (Streamlit Community Cloud, plus a GitHub Pages backup), set its sharing to public, and reviewed the final report, slides and dashboard. I also checked that the dashboard opens without a login.
